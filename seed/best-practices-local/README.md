# Local changes

This folder is for your own changes to the framework docs in `wiki/best-practices/framework/`.

This README is a framework file. It is replaced on update, so do not edit it. Put your changes in files beside it.

- Name a file after the framework doc it changes (`wiki-authoring-best-practices.md` for a change to that doc).
- A change for every wiki on this machine goes in the global toolset's `wiki/best-practices/local/`.
- A change for this wiki only goes in this wiki's `wiki/best-practices/local/`.
- When unsure which, ask the user.
