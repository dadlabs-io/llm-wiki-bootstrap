## 2026-09-12

### `qmd query` hang root-caused: Vulkan fallback without a CUDA runtime; CUDA preflight added; truth-status filter fixed
- **Root cause, measured**: `qmd query` runs three bundled GGUF models in-process through node-llama-cpp (Ollama is not involved). With no CUDA runtime installed it fell back to Vulkan across an RTX 4070 + Intel iGPU, where token generation never returned (model loads in 2 s, a 60-token generation ran past 118 s), so every never-seen query hung at the expansion step at 100% CPU on all 32 cores; repeat queries only looked fine because expansions are cached. Four parallel ingest workers each running it locked the machine (11 stalled processes killed). CPU-only (`QMD_LLAMA_GPU=false`) generated but node-llama-cpp reported zero math cores and reranking six chunks exceeded 120 s.
- **Fix**: the CUDA 13.2 runtime — `winget install --id Nvidia.CUDA --version 13.2 --exact --override "-s cudart_13.2 cublas_13.2"` (runtime + cuBLAS only; 13.1+ toolkits no longer bundle a driver; node-llama-cpp's prebuilt CUDA binary needs 13.1+). After it: `gpu=cuda`, 24 math cores, the hung generation takes 0.8 s, a fresh full `qmd query` runs in 16 s. Shells opened before the install lack the CUDA PATH until restarted.
- **Policy (user decision)**: local search stays the default; there is no cloud fallback. `/wiki-search` gains a **CUDA preflight** (`node-llama-cpp inspect gpu` must print `CUDA: available`) and runs `qmd query` under `timeout 120`; a failed preflight or a timeout is reported and fixed, never worked around. Parallel ingest workers use `qmd search` (keyword, no model) — one GPU cannot host several model-loading processes; `qmd query` is for the interactive session. `/wiki-update` step 3, `/wiki-discover`, the `wiki-ingester` agent and its reading list say the same.
- **`wiki-search-rerank.py` fixed** to accept qmd 2.1's bare-list JSON and its `qmd://` file URIs — before this every row was dropped as "does not exist on disk" (or the script crashed on a list).
- **Migration**: `install-wiki.ps1 -RefreshOnly`; install the CUDA runtime on any machine where the preflight fails.
