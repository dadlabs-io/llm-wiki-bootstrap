# BM25 versus embeddings for agent memory

## TL;DR
Keyword scoring and dense vectors miss different queries, so an agent memory that fuses both recalls more than either alone.

## What
A short summary of a comparison of BM25 and embedding retrieval over an agent's stored memories, and of the fusion that beat both.
