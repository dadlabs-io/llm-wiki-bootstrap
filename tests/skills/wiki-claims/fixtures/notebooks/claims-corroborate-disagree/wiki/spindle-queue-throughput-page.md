# Spindle queue throughput page

## TL;DR
A benchmark page states that the Spindle message queue sustained 120,000 messages per second on a three-node cluster.

## Setup
The page describes a three-node cluster with default settings and a producer that sends 256-byte messages. It reports a sustained rate of 120,000 messages per second for ten minutes.
