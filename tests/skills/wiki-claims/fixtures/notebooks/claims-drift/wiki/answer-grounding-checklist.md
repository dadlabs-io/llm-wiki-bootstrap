# Answer grounding checklist

## TL;DR
The support team adopted a short grounding checklist in July 2026. Reviewers tick each item before an answer goes out.

## The checklist
Check that each statement in the answer appears in the retrieved text. Remove any statement that does not. Add a link to the source for every figure.

## Adoption
Eight reviewers use the checklist. It takes about two minutes per answer.
