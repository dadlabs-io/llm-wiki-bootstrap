# Handoff files between agent sessions

## TL;DR

A short handoff file (the goal, what is done, what is next and the first file to open) lets a new agent session pick up where the last one stopped, without re-reading the whole history.

## What it says

- The handoff stays under a page; longer notes go into dated journals that are read only on request.
- The next session reads the handoff before its first reply.
- The failure that remains is a handoff that records what was done but not what was decided, so a settled question gets reopened.

## Why it matters here

It is the memory side of context engineering: a small, curated note carried between sessions instead of the full transcript.
