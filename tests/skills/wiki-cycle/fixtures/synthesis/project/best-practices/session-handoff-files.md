# Session handoff files

## TL;DR

End every session by writing a short handoff file that says what was done, what is open and what comes next.

## The practice

- Write the file before the session ends, not after.
- Keep it to one screen so the next session reads it whole.

## Why it matters

The next session starts with no memory of this one; the file is the only thing that carries the thread.
