# raw/

Verbatim dumps of external sources that were ingested. **Append-only.** Never edit or delete raw files — the wiki entry is the curated synthesis; raw is the receipt.

Empty on fresh install. Populated by `/wiki-update` and `/wiki-cycle` as sources are fetched.

Naming convention: `<YYYY-MM-DD>-<slug>.md` or `<YYYY-MM-DD>-<slug>.<ext>` (for PDFs, transcripts, etc.).
