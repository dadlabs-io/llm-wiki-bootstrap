# Specialized Best Practices

This folder contains best practices for **specific technologies or frameworks** (e.g., Unity, React, Python).

## Usage Rule

🚨 **DO NOT include these in `core-dev-reading-list.json`.**

These are **OPT-IN**. If your project uses one of these technologies:
1. Copy the file to your project's `memory-bank/long-term/best-practices/`.
2. Add it to your project-specific `memory-bank/reading-lists/dev-reading-list.json`.

## Available Docs
- **unity-best-practices.md**: Unity project standards, prefabs, and editor scripting.
- **ui-best-practices.md**: UI patterns for Unity/C# projects.
