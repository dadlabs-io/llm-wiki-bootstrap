# Concept Gaps — Things Mentioned, Not Yet Covered

A running tracker of concepts, projects, people, and frameworks that are **mentioned** in your wiki entries but **don't have their own page yet**. Populated by `/wiki-cycle --full`'s semantic lint pass. Each row is a candidate for future ingestion.

## How to read this

| Column | Meaning |
|---|---|
| **Priority** | 1 = central to discussions (ingest ASAP), 5 = passing reference |
| **Concept** | The thing mentioned |
| **Type** | Project / person / framework / concept / paper |
| **Mentioned in** | Which wiki entry/entries reference it |
| **Notes** | Why it matters, what you'd want to learn |

When you eventually ingest one via `/wiki-update`, the integration step adds the new entry AND removes the row from this table. Semantic lint re-evaluates this list each `--full` run.
